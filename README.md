# SmartQueue

> Good food. Less waiting.

## Description
SmartQueue is a campus canteen pre-ordering system that lets students browse
stalls, order ahead, and pick up their food at a set time, so they spend less
time waiting in line.

## Features
- Login with school email and password
- Create an account
- Dashboard with featured stalls and live average wait time
- Menu browsing by stall and category
- Search for today's menu
- Add to bag and checkout
- "Your usual picks" quick reorder

## How to Run
1. Clone the repo: `git clone https://github.com/fbajala566262-lang/SmartQueue.git`
2. Open Eclipse, then go to File → Import → Existing Projects into Workspace
3. Select the cloned SmartQueue folder and click Finish
4. Make sure a Java JDK is installed (Eclipse will tell you if not)
5. Right-click [Main.java] → Run As → Java Application
6. Login: [test email / password]
