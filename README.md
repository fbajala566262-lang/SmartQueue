# SmartQueue

> Good food. Less waiting.

## Description
SmartQueue is a campus canteen pre-ordering system that allows the students to browse
stalls, order ahead, and pick up their food at a set time, so they spend less
time waiting in line. This is the initial progress version (UI with basic
working features).

## Features
- Login with school email and password
- Menu browsing by stall and category
- Add to bag with quantity controls
- Order tracking with status updates (Queued, Preparing, Ready, Picked up)
- Canteen map tab
- Create an account (planned)
- Search today's menu (planned)

## How to Run
1. Clone the repo: `git clone https://github.com/fbajala566262-lang/SmartQueue.git`
2. Open Eclipse IDE and create a new project: File → New → Java Project (use JDK 17 or newer)
3. Copy the `View` folder from the repo's `src` folder into the new project's `src` folder
4. Right-click `Main.java` → Run As → Java Application
5. Login: enter any school email (e.g. test@school.edu) and any password with 4 or more characters

## Project Structure
